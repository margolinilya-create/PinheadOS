# Правила обзора 26.09 (сессия 69) — код-ревью, уборка, оптимизация

Отчёт — `docs/2026-09-26-project-review.md`. Здесь — правила, которые
сессия добавила или уточнила.

- **Пакет оболочки (`erp_bootstrap`) — первый кадр, а не загруженный раздел.**
  Его строки беднее, чем у загрузчиков экранов (`loadSubcontracting`,
  `loadExperimental` несут `moves`, `attachments`, `order.due_date`). Пакет
  кладёт строки в ещё не загруженный раздел и НЕ ставит `*Loaded`;
  загруженный раздел не перезаписывает. Realtime перечитывает раздел, если
  флаг стоит ИЛИ строки есть, — иначе бейдж сайдбара застывает на снимке
  входа. Сторож `bootstrapSlice.test.ts` читает SQL пакета: добавите эмбеды
  в RPC — он скажет пересмотреть слайс.
- **Коалесценция realtime живёт в `store/realtimeCoalesce.ts`.** Событие
  приходит по строке, перечитывание — по сущности: серия закрывается
  таймером, таймер на заказ — свой (`Map` по id). Отложенное событие
  повторяет проверку ОБОИХ ключей (`stage:` и `route:`), иначе повтор
  заходит с полным запасом попыток.
- **Возврат вкладки — один `resyncRealtime`.** `focus` не слушается
  (`visibilitychange` его покрывает), второй запуск поверх идущего гасится
  флагом `realtimeResyncing`.
- **`init()` авторизации — один на процесс** (`initInFlight`); из `App`
  эффект снят, `main.jsx` зовёт его до рендера.
- **`useErpStore()` без селектора запрещён** — подписка на весь стор.
  Сторож `selectorRequired.test.ts`.
- **Кэш ответа не замечает новую строку по тому же ключу сам.** Ключ версии
  приносит вызывающий: журнал переделок кэшируется по `id:qty_rework`, и
  второй возврат по этапу обходит 30-секундный кэш.
- **Сторож, читающий файлы, работает в node.** Первой строкой —
  `// @vitest-environment node`; DOM-моки `setupTests.js` — только под
  `typeof window !== 'undefined'`. `migrations.testutil` кэширует каталог,
  тексты и ответы `latestMatching`; обходчик исходников —
  `src/testutil/sourceFiles.ts`, копий в тестах не заводить.
  Сторожа `guardEnv.test.ts`, `migrations.testutil.test.ts`.
- **Дата для показа разбирается `utils/date.parseDateLocal`.** Строка
  `YYYY-MM-DD` через `new Date()` — это UTC-полночь, западнее Гринвича
  предыдущий день. Сторож в `utils/deadline.test.ts` запрещает
  `new Date(<срок>)`; `URGENT_DAYS` живёт в `utils/date` — визард
  Order Studio не тянет модуль времени ERP ради числа.
- **Сырой байт 0x00 в исходнике запрещён** — grep считает файл бинарным
  и молча пропускает. Разделитель ключа ячейки — `CELL_SEP` из
  `utils/cellKey.ts`. Сторож `cellKey.test.ts`.
- **Индекс снимается по `pg_get_indexdef` и `pg_stat_user_indexes`, а не по
  имени из миграций.** «Покрывающий» индекс может оказаться частичным
  (`where …`) и запрос по первой колонке не обслуживать — так разведка чуть
  не сняла индекс с 76 042 чтениями.
- **Changelog — `docs/changelog/<YYYY-MM>.md`**, запись сессии выше прежних;
  `PROJECT.md` держит только историю, статистику и roadmap. Сторож
  `changelogIndex.test.ts` не даёт записям копиться обратно.
- **Ключ объекта Storage при переименовании — тот же набор символов, что
  при загрузке**: `~` в имени версии ронял ночную копию InvalidKey.
- **Ратчет размера — не помеха правке, а указание вынести кусок**:
  за сессию из ратчетных файлов вынесены `orderFormGrid.ts`,
  `realtimeHelpers.ts`, `authHelpers.ts`, `reworkEvents.ts`.
- **Полный прогон тестов и линт не запускать одновременно в контейнере
  с 16 ГБ** — процесс убивается по памяти (код 137); `--maxWorkers=3`
  и по очереди.
