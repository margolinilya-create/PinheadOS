### Решения

- Справочники заказа правит руководство продаж (admin, director, rop); каталог моделей, тканей
  и общий прайс (`/sku`) — admin, director.
- Защита от затирания — сравнение с базой на сервере, md5 на клиенте не нужен; прямая запись
  в таблицы справочников не закрыта (решение владельца), только `active and approved`.
- МС — признак `profiles.is_ms` на стороне ТЗ; ERP не меняется.
- Порог маржи — подсказка; сервер доверяет `price_total`. Тексты справочников в PDF вехи 6 — только
  текстовым API.

### Следующие шаги и бэклог

- **Бюджет бандла на пределе** (веха 5 — первым пунктом плана): оболочка ERP JS ~194,4 из 195 КБ,
  CSS 15905 из 16000 Б (запас 95 Б). CSS держится на приёме в `OrderSettings.jsx` — запасной
  `EmptyState` из `ErpStates` нужен, чтобы Rollup не вынес `erp.module.css` в отдельный чанк. Любой
  новый импорт ERP-примитива в Order почти наверняка выйдет за бюджет: обсудить с владельцем поднятие
  бюджета или вынос `Tabs` в снимок CSS оболочки Order.
- Сервер не проверяет, что цена бирки с материалом ≥ 0 (клиент ограничивает снизу нулём).
- Перегрузка `sales_set_staff(uuid, boolean)` — убрать до вехи 5.
- Цены бирок в экспрессе и старом визарде — на константах `pricingCore`, не из библиотеки.
- `SkuColorPicker` / `allowedColors` знают только палитру Медастекс.
- Старые ключи `catalog_config.{prices, labels, extras, fabrics}` — вне белого списка записи; решить,
  убирать ли.
- `prices_patch` не заводит ключ прайса, которого нет в базе (прежний upsert целиком заводил):
  сверить на бою, все ли ключи `PRICES` уже есть в `app_config.prices`.
- `order_v4_transition` / `_launch_check` считают автора по `role = 'manager'`, а не по `is_sales`
  (миграция B) — расхождение с `sales_is_seller()`.
- Рамка круга образца в `ColorPicker` (`rgba(0,0,0,.12)`) не даёт 3:1 на светлых цветах.
- Аудит смены `is_sales` / `is_ms` (кто и когда).
- `reorderSku` в `productSlice` больше не вызывается приложением — удалить отдельной уборкой.
- Вехи 5–8: дизайн-мейкер и превью бирок (5), ТЗ в PDF + отправка и оплата (6), «К запуску» (7),
