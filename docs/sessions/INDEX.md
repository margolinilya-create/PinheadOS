**Как пользоваться.** Нужна сессия — берите строку таблицы. Нужна тема —
`grep -rn "слово" docs/sessions/`. Правила из этих разборов вынесены отдельно —
`docs/rules/INDEX.md`; changelog — `PROJECT.md`.

⚠️ Это журнал, а не справочник: запись описывает состояние НА СВОЮ ДАТУ.
Прежде чем действовать по ней, сверьтесь с живой базой и кодом — у проекта
не раз «устаревшая запись становилась инструкцией сделать уже сделанное».
