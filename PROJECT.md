# Pinhead Order Studio — Проект

## История

### ERA 1 — Vanilla HTML (до марта 2026)
Весь проект в одном файле `pinhead-order-studio-v1_7__5_.html` (~9 500 строк).
Supabase через CDN. Финальная версия v1.7 — полностью функциональна для внутреннего использования.

Ушли от vanilla потому что: файл неподдерживаем, нет тестов, нет типов, невозможно масштабировать.

### ERA 2 — React Migration (февраль–март 2026)
Полная миграция в React 19 + Zustand. 138 коммитов. Воспроизведён весь функционал v1.7.

Ключевая сессия — 20 марта 2026 (56 коммитов): ревизия по Design Guidebook, 5 критических багов, 65 тестов на pricing.

### ERA 3 — Стабилизация + CRM/ERP (апрель 2026)
Сессии 1-5: баги, качество, UX, аудит UI, security hardening. Стратегический разворот к CRM/ERP интеграции.

## Roadmap

> Переписан 24.09 (сессия 68) под факт. Прежняя редакция была апрельской:
> «Фаза 2 — планирование производства (следующая)» при сделанных `/plan`,
> `/gantt`, `/load`, и таблица без единого признака ERP.

### Сделано (ERP, июль–сентябрь 2026)
- Производство: заказы и позиции с ТЗ, маршрут этапов по цехам, очереди цехов,
  канбан, задания, финальный ОТК, подряд, экспериментальный цех (разработка
  образцов), склад (приёмка, маркировка, упаковка, отгрузка частями), закупка
  (варианты поставщиков, приёмка частями, рулоны и их вес, остатки полотна).
- Планирование: недельный план `/plan` — РУЧНОЙ по решению заказчика,
  загрузка цехов `/load`, Гант `/gantt`; мощность — в штуках за месяц.
- Права: матрица ролей на клиенте и на сервере (`erp_has_permission`),
  девять стражей UPDATE, RLS на всех таблицах, аварийный режим.
- ТЗ в PDF у позиции и заказа, каталог моделей SKU, чат внутри сделки
  с уведомлениями и реакциями, аналитика и экономика позиции.
- Эксплуатация: CI (unit, e2e, визуальные эталоны, бюджет бандла), защита
  `main`, журнал миграций со сверкой с продом, сбор ошибок интерфейса
  (`erp_client_errors`), ночная копия Storage.
- Order Studio (за флагом): рабочее место заказа v4 (веха 3, визард v3 как экран убран),
  справочники заказа и «Сотрудники продаж» с МС на стороне ТЗ (веха 4),
  вкладка «Дизайн» — холст с флэтом позиции, логотипы, PDF макета, типовые флэты (веха 5а),
  SKU-редактор, экспресс-расчёт; номер заказа из последовательности (`generate_order_number`, 24.09).
