# Фикстуры образцов ТЗ (веха 6+7, задача 2; К25)

Пять заказов v4 по образцам владельца (спека `docs/superpowers/specs/2026-10-16-unified-order-flow-design.md`,
строка 129): 63886 «Эквилент Олд Мани», 67108 «Фертоинг» (образец), 68180 «АО НАВИС» (футболка, свитшот, поло).
PDF образцов в репозитории нет — фикстуры собраны по описанию спеки (строки 128–223) и разбору
`docs/erp/tz-format-analysis.md`. Значения, которых в описании нет (размеры, мм, имена людей, сетки),
придуманы правдоподобно и помечены ниже «П». **Ручная сверка с PDF образцов — владельцем до включения
флага (веха 8).**

- `<номер>.json` — заказ: только поля образца, остальное добирают фабрики модели (`model/factory`).
  У 68180 три файла — одна сделка: заказ = шапка `68180-tee` + позиции трёх файлов по порядку
  (`loadFixture.testutil.ts`); `group` — номер ТЗ в заказе с нуля.
- `<номер>.tz.json` — ожидаемые поля `tzDocument()` (сравнение `toMatchObject`: перечисленное
  обязано совпасть, массивы — целиком). Дата оформления `2026-10-18`, адрес `https://pinhead-os.vercel.app`.
- `catalogs.json` — справочники (ткани, обработки, бирки и схемы, упаковка, зоны, флэты, подвал).
- Ожидания закоммичены ОТДЕЛЬНЫМ коммитом до реализации — иначе равенство проверяло бы
  согласованность исполнителя с самим собой.
