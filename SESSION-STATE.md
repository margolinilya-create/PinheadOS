### Решения

- Продавец — явный признак `profiles.is_sales` (ставит admin/director); `rop` — «Заказы отдела»,
  admin/director — «Все заказы»; остальные роли (в том числе начальники цехов с профилем `manager`)
  в разделе ТЗ сразу попадают в «Производство».
- Один цвет = одна позиция: многоцветную позицию правят только после «Разнести по цветам».
- Скидку и ручную цену менеджер ставит сам; ниже порога маржи — предупреждение.
- **`SALES_CLIENT_REV` — всегда пара «клиент + миграция»; миграция — после выкладки фронта;
  откат фронта — сначала откат миграции.** Любое будущее RPC, меняющее заказ (веха 6: переход,
  оплата), обязано положить новый `updated_at` в `current`, иначе ложный `conflict`.
- Бюджет оболочки ERP держится на том, как Rollup режет чанки `ErpStates`/`ErpSkeletons`
  (запас JS 889 Б на 17.10): новый импорт ERP-примитива в Order — сверять `npm run bundle:budget`.
