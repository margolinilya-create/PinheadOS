Решение владельца: **ERP — рабочая система, её не трогаем.** Из среза 0 сделано
всё, что живёт в Order; пункты, требующие правок ERP или общей инфраструктуры
(таблица цены продажи `erp_*`, гейт деплоя, `sales_order_id` у тредов ERP),
отложены до явного решения.

- `utils/pricingCore.ts` — формула цены без стора (цены аргументом);
  `utils/pricing.ts` — прежний API визарда обёртками. Регресс 88 тестов без правок.

- `orderstudio/pricing/priceOrder.ts` — цена заказа: нанесение по тиражу группы
  размеров, формат из мм, округление вверх до 5 ₽, срочность, подготовка раз
  на технику, скидка, порог по итоговой марже, ручная цена; 16 тестов.
- `orderstudio/bridge/tzToErpDraft.ts` — контракт моста: заказ v4 → форма ERP
  + `tz_order_id`/`tz_number`; у каждого поля формы ERP — источник или причина;
  сторож читает интерфейсы из `erp/utils/orderForm.ts` (проверен мутацией); 21 тест.
- Файлы ERP не менялись: `git diff origin/main -- pinhead-react/src/erp supabase` пуст.
